# Templates

Fillable markdown templates for common PM documents. Copy, fill in, ship — no Claude required.

## Available Templates

| Template | Use When |
|----------|----------|
| [PRD](prd-template.md) | Scoping a new feature or initiative |
| [OKRs](okr-template.md) | Setting quarterly goals and running check-ins |
| [Sprint Retro](retro-template.md) | End-of-sprint retrospective |
| [Decision Log](decision-log-template.md) | Recording significant product or technical decisions |
| [Stakeholder Update](stakeholder-update-template.md) | Weekly or milestone status updates |
| [Competitive Analysis](competitive-analysis-template.md) | Competitor teardown and sales battlecard |

## How to Use

1. Open the template file
2. Copy the raw markdown
3. Paste into your doc tool (Notion, Confluence, Google Docs, etc.)
4. Fill in the bracketed placeholders — `[like this]`
5. Delete any sections not relevant to your use case

## Templates vs. Skills

**Use a template** when you want a blank structure to fill in yourself.  
**Use a skill** when you want Claude to fill it in based on your inputs.

They're complementary — the templates match the output format of their corresponding skills, so you can use either interchangeably.
