## How to Use This Section

Each framework document covers:
1. **What it is** — the core idea in plain language
2. **When to use it** — the specific situations where it adds the most value
3. **How to apply it** — step-by-step for a PM context
4. **Worked example** — applied to Pulse, the fictional product used throughout this repo
5. **Common mistakes** — how the framework gets misused
6. **Connections** — how it links to other frameworks and skills in this repo

## The Meta-Point

Frameworks are thinking tools, not answers. The PM who knows ten frameworks and applies them mechanically produces worse outcomes than the PM who knows three frameworks and knows when each one doesn't apply.

Use these to structure your thinking. Override them when reality doesn't fit the model.
