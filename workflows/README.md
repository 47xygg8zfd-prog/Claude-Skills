# PM Skill Workflows

Step-by-step guides for chaining multiple skills together to complete common PM workflows end-to-end.

## Workflows

| Workflow | Skills Used | Use When |
|----------|-------------|----------|
| [Discovery to Delivery](discovery-to-delivery.md) | Research Synthesis → Prioritization → PRD → Stories → Monte Carlo → Sprint Planning → Data Queries → Release Notes → Stakeholder Updates | Starting a new feature from scratch |
| [Research to Roadmap](research-to-roadmap.md) | Research Synthesis → Competitive Analysis → Prioritization → OKRs → Presentations → Stakeholder Updates | Quarterly planning cycle |
| [Incident & Risk Comms](incident-to-comms.md) | Tech Translation → Data Queries → Stakeholder Updates → Release Notes → Agile Ceremonies | Something went wrong and needs clear communication |

## How to Use These

Each workflow doc explains:
- **Which skills to use and in which order**
- **What prompt to use to kick off each step**
- **What output to carry forward to the next step**
- **Tips for common mistakes or shortcuts**

The fastest way to run any workflow is to have [CLAUDE.md](../CLAUDE.md) filled in — it pre-loads your product context so each step needs less setup.
